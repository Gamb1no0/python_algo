# Validate

В `validate.py` находится решение, в `test_validate.py` — тесты.

## Как работает

Просто повторяем операции со стеком. Добавляем числа из `pushed` по порядку. После каждого добавления смотрим на вершину: если она равна следующему числу из `popped`, удаляем её и переходим к следующему числу в `popped`. Продолжаем удалять, пока есть совпадения.

Стек хранится в обычном списке Python: `append()` добавляет в конец, `pop()` удаляет последний элемент. Переменная `index` показывает, какое число из `popped` нужно получить следующим. Входные списки не меняются, сторонних библиотек нет.

Если вершина совпала с нужным числом, её можно сразу удалить. Добавлять сверху другие числа перед этим нет смысла: они закроют нужный элемент, а удалить их раньше него нельзя по порядку `popped`. Если вершина не совпадает, остаётся добавлять следующие числа из `pushed`. Поэтому такая проверка найдёт допустимый порядок операций, если он существует.

В конце возвращаем `True`, если удалось получить все числа из `popped`. Иначе возвращаем `False`.

По условию числа уникальны, а `popped` — перестановка `pushed`. Дополнительно для двух пустых списков возвращается `True`, для списков разной длины — `False`.

## Сложность

Время — O(n), где n — длина последовательности. Каждый элемент добавляется в стек один раз и удаляется не больше одного раза. Добавление в конец списка занимает O(1) в среднем по серии операций, удаление с конца — O(1).

Дополнительная память — O(n): в худшем случае в стеке окажутся все элементы, например при обратном порядке удаления. Считаем операции сравнения целых чисел за O(1).

## Пример

`pushed = [1, 2, 3, 4, 5]`, `popped = [1, 3, 5, 4, 2]`.

Вершина стека показана справа. В последнем столбце — следующее нужное число после выполнения операции.

| Операция | Стек | Следующее число из popped |
| --- | --- | --- |
| push(1) | [1] | 1 |
| pop() → 1 | [] | 3 |
| push(2) | [2] | 3 |
| push(3) | [2, 3] | 3 |
| pop() → 3 | [2] | 5 |
| push(4) | [2, 4] | 5 |
| push(5) | [2, 4, 5] | 5 |
| pop() → 5 | [2, 4] | 4 |
| pop() → 4 | [2] | 2 |
| pop() → 2 | [] | Все числа получены |

Получили нужный порядок, ответ — `True`.

Для `pushed = [1, 2, 3]` и `popped = [3, 1, 2]` после удаления 3 в стеке останется `[1, 2]`. Нужно удалить 1, но сверху лежит 2, а новых чисел для добавления уже нет. Ответ — `False`.

## Как запустить

Из папки `homework_2/validate`:

```bash
python3 validate.py
```

Вводим две строки: сначала `pushed`, потом `popped`, числа через пробел. Например:

```text
1 2 3 4 5
1 3 5 4 2
```

Программа выведет `True`.

Запуск тестов из той же папки:

```bash
python3 -m unittest -v
```

Тесты проверяют примеры из задания, один элемент, прямой и обратный порядок, разные допустимые и невозможные перестановки, отрицательные числа и ноль. Ещё проверяются сохранность входных списков и последовательности из 100000 элементов. Для дополнительных случаев есть проверки пустых списков и разной длины. Используется стандартный unittest, ничего устанавливать не надо.
