# Two sum

В `two_sum.py` находится решение, в `test_two_sum.py` — тесты.

## Как работает

Идём по массиву слева направо. В словаре `seen` храним уже просмотренные числа и их индексы. Для текущего числа `number` ищем в словаре число `k - number`. Если нашли, возвращаем его индекс и текущий индекс. Если нет, добавляем текущее число в словарь и идём дальше.

Сначала проверяем пару, а потом добавляем число. Так один и тот же элемент не используется дважды. При этом два одинаковых числа на разных местах подходят: для `[5, 5, 1, 4]` и `k = 10` получим `(0, 1)`.

Когда дойдём до второго элемента нужной пары, первый уже будет в словаре. Значит, пара обязательно найдётся. Первый индекс всегда меньше второго, поэтому сортировать ответ не надо. Индексы начинаются с нуля, входной массив не меняется.

По условию подходящая пара ровно одна. Дополнительно, если пары нет, функция выдаёт `ValueError`.

## Сложность

Время — O(n) в среднем, где n — длина массива: проходим его один раз, поиск и добавление в словарь занимают O(1) в среднем. В худшем случае из-за коллизий в словаре время может быть O(n²).

Дополнительная память — O(n): храним просмотренные числа и индексы. В этой оценке считаем арифметические операции с числами за O(1).

## Пример

`arr = [8, 2, 11, 7, 4]`, `k = 9`.

Словарь в таблице показан до обработки текущего элемента. Запись `8: 0` означает, что число 8 находится на индексе 0.

| Индекс | Число | Ищем | Словарь | Что делаем |
| --- | --- | --- | --- | --- |
| 0 | 8 | 1 | {} | Не нашли, записываем 8: 0 |
| 1 | 2 | 7 | {8: 0} | Не нашли, записываем 2: 1 |
| 2 | 11 | -2 | {8: 0, 2: 1} | Не нашли, записываем 11: 2 |
| 3 | 7 | 2 | {8: 0, 2: 1, 11: 2} | Нашли 2 на индексе 1, возвращаем (1, 3) |

`arr[1] + arr[3] = 2 + 7 = 9`. До последнего элемента идти уже не нужно.

## Как запустить

Из папки `homework_3/two_sum`:

```bash
python3 two_sum.py
```

В первой строке вводим числа массива через пробел, во второй — k:

```text
1 3 4 10
7
```

Программа выведет индексы через пробел:

```text
1 2
```

Запуск тестов из той же папки:

```bash
python3 -m unittest -v
```

Тесты проверяют оба примера, два элемента, одинаковые числа, отрицательные числа и нули, пару в начале и конце массива, запрет использовать элемент дважды, большие числа и массив из 100000 элементов. Ещё проверяются сохранность массива, отсутствие пары и ввод-вывод программы. Используется стандартный unittest, ничего устанавливать не надо.
