# Anagrams

В `anagrams.py` находится решение, в `test_anagrams.py` — тесты.

## Как работает

Сортируем буквы каждого слова и получаем ключ. Например, для `eat`, `tea` и `ate` ключ будет один и тот же: `aet`.

В словаре `groups` по этому ключу хранится список слов. Если ключ встретился первый раз, создаём пустую группу. Потом добавляем туда слово. В конце возвращаем все группы.

У анаграмм одинаковые буквы и одинаковое количество каждой буквы. Значит, после сортировки получаются одинаковые строки. И наоборот: если отсортированные строки совпали, слова состоят из одинаковых букв, поэтому их можно положить в одну группу.

Порядок групп в условии не задан. Здесь группы идут в порядке первого появления, а слова внутри — в порядке входного списка. Поэтому порядок в ответе может отличаться от примера. Повторы слов сохраняются, входной список не меняется. Регистр учитывается: `Eat` и `eat` попадут в разные группы. Пробелы и другие символы тоже учитываются.

## Сложность

Пусть n — количество слов, а L_i — длина i-го слова.

Время — O(n + сумма L_i · log(L_i + 1)). Для каждого слова сортируем символы, а затем создаём ключ и добавляем слово в группу. При L_i >= 2 это обычная оценка O(L_i log L_i). Добавка n учитывает проход по словам, включая пустые строки. Операции со словарём считаем за O(1) в среднем после вычисления хеша ключа; обработка самого ключа занимает O(L_i).

Дополнительная память — O(n + сумма L_i): храним ключи и списки ссылок на слова. Сами исходные строки не копируются.

## Пример

Вход: `["eat", "tea", "tan", "ate", "nat", "bat"]`.

| Слово | Ключ | Группы после добавления |
| --- | --- | --- |
| eat | aet | [[eat]] |
| tea | aet | [[eat, tea]] |
| tan | ant | [[eat, tea], [tan]] |
| ate | aet | [[eat, tea, ate], [tan]] |
| nat | ant | [[eat, tea, ate], [tan, nat]] |
| bat | abt | [[eat, tea, ate], [tan, nat], [bat]] |

Ответ: `[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]`.

## Как запустить

Из папки `homework_3/anagrams`:

```bash
python3 anagrams.py
```

Вводим список слов в одной строке, в формате JSON с двойными кавычками:

```text
["eat", "tea", "tan", "ate", "nat", "bat"]
```

Вывод:

```text
[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

Так можно ввести и пустые слова: `["", "a", ""]`.

Запуск тестов из той же папки:

```bash
python3 -m unittest -v
```

Тесты проверяют пример, пустой список, одно слово, пустые слова, повторы, слова без анаграмм, разное количество одинаковых букв, кириллицу, регистр и другие символы. Ещё проверяются порядок результата и сохранность входного списка. Используются только стандартные `json` и `unittest`, ничего устанавливать не надо.
