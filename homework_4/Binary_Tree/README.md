Три задачи из ДЗ. Используется Python 3.10+, сторонние библиотеки не нужны.

```text
homework_4/Binary_Tree/
├── task_1.py          # BST, вставка, 6 обходов
├── task_2.py          # Проверка BST
├── task_3.py          # Проверка баланса
├── test_binary_tree.py
└── README.md
```

**Запуск тестов** из папки `Binary_Tree`:

```bash
python -m unittest -v
```

В BST считаем ключи уникальными: повторная вставка ничего не меняет.

## Задача 1. Tree Traversal

**Решение:** `task_1.py`.

**Идея и корректность.** `BST.insert()` сравнивает ключ с текущим узлом: меньший ключ вставляет в левое поддерево, больший — в правое. Если место пусто, создаёт узел. Поэтому после каждой вставки сохраняется свойство BST. Шесть обходов отличаются порядком обработки текущего узла (N), левого (L) и правого (R) поддеревьев. В каждом случае рекурсия посещает каждый узел один раз.

**Сложность.** Вставка: `O(h)` времени и `O(h)` памяти стека, где `h` — высота дерева (`O(log n)` при сбалансированном дереве, `O(n)` в худшем случае). Каждый обход: `O(n)` времени и `O(n)` памяти для результата плюс `O(h)` для стека (всего `O(n)`).

**Визуализация (последовательность вставок `[8, 3, 10, 1, 6, 14, 4, 7, 13]`):**

```text
          8
        /   \
       3     10
      / \      \
     1   6      14
        / \     /
       4   7   13
```

Последняя вставка (`13`) выполняется по шагам: `13 > 8` → вправо; `13 > 10` → вправо; `13 < 14` → влево; пустое место → новый узел `13`.

Результаты шести обходов этого дерева:

```text
preorder          NLR:  8, 3, 1, 6, 4, 7, 10, 14, 13
inorder           LNR:  1, 3, 4, 6, 7, 8, 10, 13, 14
postorder         LRN:  1, 4, 7, 6, 3, 13, 14, 10, 8
reverse_preorder  NRL:  8, 10, 14, 13, 3, 6, 7, 4, 1
reverse_inorder   RNL: 14, 13, 10, 8, 7, 6, 4, 3, 1
reverse_postorder RLN: 13, 14, 10, 7, 4, 6, 1, 3, 8
```

**Тесты:** в `test_binary_tree.py` проверяются все шесть обходов, пустое дерево, один узел, повторы ключей, возрастающая и убывающая последовательности вставок, отрицательные ключи.

## Задача 2. Validate BST

**Решение:** `task_2.py` (`is_valid_bst`).

**Идея и корректность.** Для каждого узла проверяем допустимые границы `low < value < high`, унаследованные от всех предков. Для левого поддерева верхней границей становится значение родителя, для правого — нижней. Так обнаруживаются не только неправильные прямые дети, но и нарушения глубоко в дереве. Пустое дерево считается корректным BST; дубликаты недопустимы.

**Сложность.** `O(n)` времени — каждый узел проверяется не более одного раза; `O(h)` памяти — стек рекурсии.

**Визуализация (некорректное дерево):**

```text
       10
      /  \
     5    15
         /  \
        6    20
```

Пошаговая проверка проблемной ветки:

1. Узел `10`: ограничений нет → подходит.
2. Узел `15`: допустимо `value > 10` → подходит.
3. Узел `6`: допустимо `10 < value < 15`, но `6 <= 10` → **False**.

**Тесты:** пустое дерево, один узел, корректный BST, нарушение у ребёнка, нарушение глубже в левом и правом поддеревьях, дубликаты, отрицательные ключи.

## Задача 3. Balanced Binary Tree

**Решение:** `task_3.py` (`is_balanced`).

**Идея и корректность.** Рекурсивно вычисляем для каждого поддерева пару `(высота, сбалансировано ли оно)`. Для пустого дерева высота `-1`, для листа `0`. Узел сбалансирован, только если оба поддерева сбалансированы и разница их высот не больше `1`. Проверяются **все узлы**, а не только корень.

**Сложность.** `O(n)` времени — высота каждого поддерева считается один раз; `O(h)` памяти — стек рекурсии.

**Визуализация (у корня высоты равны, но всё дерево не сбалансировано):**

```text
          8
        /   \
       3     10
      / \      \
     1   6      14
        / \     /
       4   7   13
```

Пошаговое вычисление высот снизу вверх:

1. У листьев `1, 4, 7, 13` высота `0`.
2. У узла `14`: высоты детей `0` и `-1`, его высота `1`, баланс соблюдён.
3. У узла `10`: высоты детей `-1` и `1`, разница `2` → **баланс нарушен**.
4. У узла `3`: высоты детей `0` и `1`, его высота `2`, баланс соблюдён.
5. У корня `8`: высоты детей `2` и `2`, но справа уже есть несбалансированный узел `10` → **False**.

**Тесты:** пустое дерево, один узел, полностью сбалансированное дерево, разница высот ровно `1`, длинная цепочка, нарушение глубоко в поддереве, произвольное бинарное дерево (не BST).
