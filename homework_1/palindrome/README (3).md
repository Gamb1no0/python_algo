# Палиндром

В `palindrome.py` находится решение, в `test_palindrome.py` — тесты.

Идея простая: переворачиваем число и сравниваем с исходным. Через `% 10` берём последнюю цифру, добавляем её к новому числу через `reversed_number * 10 + digit`. Потом убираем эту цифру из оставшейся части через `// 10`.

Так мы перебираем все цифры справа налево. Если полученное число совпало с исходным, значит это палиндром. Строки для проверки не используются. Для нуля функция тоже возвращает `True`, для отрицательных чисел — `False`.

## Сложность

По времени O(d), где d — количество цифр, то есть O(log n): за один проход цикла убирается одна цифра. По памяти O(1), так как нужны только несколько переменных. Здесь считаем операции с целыми числами за O(1).

Если учитывать стоимость работы с очень большими числами Python, получится O(d²) по времени и O(d) по памяти.

## Пример для 12021

В начале оставшаяся часть равна 12021, перевёрнутое число — 0.

| Шаг | Взяли цифру | Осталось | Перевёрнутое число |
| --- | --- | --- | --- |
| 1 | 1 | 1202 | 1 |
| 2 | 2 | 120 | 12 |
| 3 | 0 | 12 | 120 |
| 4 | 2 | 1 | 1202 |
| 5 | 1 | 0 | 12021 |

Получилось 12021, оно равно исходному числу. Ответ: `True`.

## Как запустить

Из папки `homework_1/palindrome`:

```bash
python3 palindrome.py
```

Вводим число. Для 121 будет `True`, для 31 — `False`.

Запуск тестов из той же папки:

```bash
python3 -m unittest -v
```

В тестах есть примеры из задания, однозначные числа, ноль, палиндромы разной длины, числа с нулями внутри и в конце, обычные непалиндромы, отрицательные и большие числа. Используется unittest, ничего дополнительно устанавливать не надо.
