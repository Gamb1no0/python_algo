# Сумма

В `sum.py` находится решение, в `test_sum.py` — тесты.

Сначала складываем все числа и заодно запоминаем самое маленькое нечётное число. Если общая сумма чётная, возвращаем её. Если нечётная — вычитаем самое маленькое нечётное.

Это работает, потому что все числа положительные: чем меньше уберём, тем больше останется. Чтобы нечётная сумма стала чётной, нужно убрать нечётную сумму. В ней обязательно будет хотя бы одно нечётное число, поэтому дешевле всего убрать только самое маленькое нечётное.

Если в массиве одно нечётное число, оно вычитается из самого себя и ответ получается 0. Для пустого массива функция тоже возвращает 0. Отрицательные числа не рассматриваются, по условию все числа положительные.

## Сложность

По времени O(n), где n — длина массива: проходим по нему один раз. Дополнительная память функции O(1), нужны только сумма и минимальное нечётное число. Сам массив при чтении ввода занимает O(n). Здесь считаем операции с целыми числами за O(1).

## Пример для 5 7 13 2 14

В начале сумма равна 0, минимальное нечётное пока не найдено.

| Взяли число | Текущая сумма | Минимальное нечётное |
| --- | --- | --- |
| 5 | 5 | 5 |
| 7 | 12 | 5 |
| 13 | 25 | 5 |
| 2 | 27 | 5 |
| 14 | 41 | 5 |

41 — нечётное, убираем 5. Получаем `41 - 5 = 36`. В сумме остаются 7, 13, 2 и 14.

## Как запустить

Из папки `homework_1/sum`:

```bash
python3 sum.py
```

Вводим числа через пробел. Для `5 7 13 2 14` будет `36`, для `3` — `0`.

Запуск тестов из той же папки:

```bash
python3 -m unittest -v
```

В тестах есть примеры из задания, пустой массив, одно число, только чётные и только нечётные числа, смешанные массивы, повторы и большие числа. Ещё проверяется, что убирается именно минимальное нечётное число и что его положение в массиве не влияет на ответ. Используется unittest, ничего дополнительно устанавливать не надо.
