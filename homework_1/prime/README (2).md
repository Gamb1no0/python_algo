# Простые числа

В `prime.py` находится решение, в `test_prime.py` — тесты.

Используется решето Эратосфена. Создаём список `is_prime` для чисел от 0 до N - 1. Сначала везде ставим `True`, кроме 0 и 1: они не простые.

Дальше идём от 2. Если число ещё отмечено как простое, ставим `False` у его кратных. Начинаем с квадрата числа: меньшие кратные уже были вычеркнуты раньше. Например, для 3 начинаем с 9, потому что 6 уже вычеркнули на шаге с 2.

Продолжаем, пока квадрат проверяемого числа меньше N. Этого достаточно: у любого составного числа есть простой делитель не больше его квадратного корня. Поэтому все составные числа будут вычеркнуты, а простые останутся. В конце считаем оставшиеся `True` через `sum(is_prime)`.

Само N не входит в список, поэтому считаются числа строго меньше N. При N <= 2 сразу возвращаем 0.

## Сложность

По времени O(N log log N). Для каждого простого p вычёркиваем примерно N / p кратных. Сумма этой работы по простым числам даёт такую оценку. Создание списка и подсчёт ответа занимают ещё O(N).

По памяти O(N), потому что храним список отметок для чисел меньше N. Операции с целыми числами считаем за O(1).

## Пример для N = 20

Сначала отмечены все числа от 2 до 19, а 0 и 1 исключены.

| Проверяем число | Какие кратные отмечаем как составные | Что остаётся отмечено как простое |
| --- | --- | --- |
| 2 | 4, 6, 8, 10, 12, 14, 16, 18 | 2, 3, 5, 7, 9, 11, 13, 15, 17, 19 |
| 3 | 9, 12, 15, 18 | 2, 3, 5, 7, 11, 13, 17, 19 |
| 4 | Пропускаем, уже отмечено как составное | 2, 3, 5, 7, 11, 13, 17, 19 |

Следующее число — 5, но 5 * 5 >= 20, поэтому цикл заканчивается. Осталось 8 простых чисел, ответ — `8`.

## Как запустить

Из папки `homework_1/prime`:

```bash
python3 prime.py
```

Вводим N. Для `10` будет `4`, для `1` — `0`.

Запуск тестов из той же папки:

```bash
python3 -m unittest -v
```

В тестах есть примеры из задания, маленькие и отрицательные N, ноль, простые числа на границе, квадраты простых чисел и значения до 10000. Ещё для N от 0 до 100 результат сравнивается с обычной проверкой делителей. Используется unittest, ничего дополнительно устанавливать не надо.
